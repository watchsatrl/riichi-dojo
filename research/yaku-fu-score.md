### 1.8 必须交代清楚的 9 个特殊情况

#### (1) 一杯口 与 二杯口 同时成立

**规则**：二杯口成立时，**只计二杯口 3 番，不再计一杯口**（两者不复合）。
来源：[中文维基·二盃口](https://wiki.queji.com/mediawiki/index.php/%E4%BA%8C%E7%9B%83%E5%8F%A3)：「不和[[一盃口]]複合」。
**实现**：一杯口与二杯口是同一维度（相同顺子组数）的互斥取值：1 组=1 番，2 组=3 番。

#### (2) 二杯口 与 七对子 是否复合

**规则**：**不复合，二选一**。同一副牌既满足二杯口（3 番）又满足七对子（2 番）时，按**高点法**取二杯口。
来源：[中文维基·二盃口](https://wiki.queji.com/mediawiki/index.php/%E4%BA%8C%E7%9B%83%E5%8F%A3)「不和[[七对子]]複合（七對和二盃，二選一）」；[中文维基·七對子](https://wiki.queji.com/mediawiki/index.php/%E4%B8%83%E5%B0%8D%E5%AD%90)「不與[[二盃口]]複合，要麼七對，要麼二盃（通常是肯定只算二盃）」；RCR 规则书同：「注：不再计算一色二顺，也不再计算七对子」。
**七对子与一杯口的常见分歧**：
- 主流（含天凤/雀魂/RCR）：**七对子与一杯口不复合**。理由：牌型拆解互斥——一组牌不可能同时被拆成「4 组对子 + 1 组顺子」还满足七对子。
- 少数线下规则允许「七对子 + 一杯口」复合（把 223344 视作 2 对 + 1 顺子），`[待核实]`，不推荐实现。
**实现要点**：七对子判定成功后，不再做顺子役判定；反过来若按顺子拆解能得更高番，按高点法选顺子拆解。

#### (3) 平和的定义（三条件，缺一不可）

1. **门清**（副露即不成立）；
2. **4 组面子全为顺子**（不能有任何刻子/杠）；
3. **雀头不能是役牌**（三元牌 / 场风牌 / 自风牌；连风牌雀头也不行）；
4. **听牌形必须是两面听**（顺子两端的开放两面；嵌张/边张/单骑/双碰均不成立）。

来源：[中文维基·平和](https://wiki.queji.com/mediawiki/index.php/%E5%B9%B3%E5%92%8C)（明确「門前清 / 雀頭不能是役牌 / 3 顺子 + 1 雀头 + 1 两面搭子」）；麻雀豆腐同（「門前 / 4面子が全て順子 / アタマは役牌以外 / 両面待ち」）。
**易错**：`11223344 型`（如 234m 234p 234s + 2344s 的 4 面子拆解）——若和牌形能被拆成**单骑**，则按高点法可保留平和（因为平和要求两面听，而高点法在选择拆解时就已确定听牌形）。`[待核实]`：各平台对「平和 + 单骑两面复合形」的处理需以实际平台验证，主流做法是「只要存在两面听的整体拆解且该拆解是高点，则给平和」。
**与一杯口关系**：平和与一杯口**可以复合**（如 234m 234m 567p 567p + 雀头 + 两面听）。

#### (4) 断幺九与副露（食断 / 喰い断）

| 平台 | 食断（副露断幺九） |
|---|---|
| 天凤 | **可选**（`喰い断なし/あり選択`），段位战各桌有「有食断」「无食断」两种设定 |
| 雀魂 | **有**（段位场规则原文：「有食断、有后付、无食替」） |
| 雀姬 | 有（1 番起和，无 5 本场 2 番缚） |
| RCR（欧洲竞技） | 有（断幺九列为一番役，未标门清限定） |

来源：[天凤官方手册·ルール](https://tenhou.net/man/)（`喰い断なし/あり選択`）；雀魂段位场规则见 [百度百科·雀魂麻将](https://wapbaike.baidu.com/item/%E9%9B%80%E9%AD%82%E9%BA%BB%E5%B0%86/60778444)。
**实现**：`kuitan` 做成配置项，默认 `true`。

#### (5) 役牌的连风牌（自风 = 场风）是否算两个役牌

| 情形 | 役牌番数 | 说明 |
|---|---|---|
| **连风牌刻子**（东场东家碰东） | **2 番** | 同时成立「役牌:场风牌」1 番 +「役牌:自风牌」1 番，**役牌可叠加** |
| **连风牌雀头**（东场东家，东为雀头） | **0 番**（但与平和互斥） | 连风雀头不构成任何役，只影响符数（见 §2.4） |

来源：[中文维基·役种表](https://wiki.queji.com/mediawiki/index.php/%E5%BD%B9%E7%A8%AE%E8%A1%A8)「役牌都是可叠加的」；雀魂役种表「役牌：自风牌 / 役牌：场风牌 / 役牌：三元牌」三行并列。
**实现**：役牌番数 = (三元牌刻子数) + (场风刻子? 1:0) + (自风刻子? 1:0)，两者独立判定。

#### (6) 三色同刻 / 三暗刻 / 四暗刻 的暗刻定义

| 问题 | 规则 |
|---|---|
| 副露的刻子（碰/明杠）算不算暗刻？ | **不算**。只数暗刻（手牌内自己摸成的刻子）+ 暗杠 |
| 荣和时，和牌张补成的刻子算明刻还是暗刻？ | **算明刻**。天凤原文：`ロン和了で完成した刻子は明刻子とし順子は暗順子とする` |
| 暗杠算不算暗刻？ | **算**。暗杠视为暗刻（符数按杠计） |
| 四暗刻（双碰听荣和） | **不成立**。双碰听荣和时，和牌张补成的刻子算明刻 → 只剩 3 暗刻。天凤役种表原文：「门清对对和，双碰听牌，**只能自摸**。（如果荣和则是三暗刻+对对和）」 |
| 四暗刻单骑 | 听牌时已有 4 组暗刻、单听雀头；**荣和或自摸均成立** |
| 三暗刻的对对和复合 | 可复合（三暗刻 2 番 + 对对和 2 番） |

来源：[天凤官方 役一覧](https://tenhou.net/man/)（`※ロン和了で完成した刻子は明刻子とし順子は暗順子とする`）；[中文维基·役種表](https://wiki.queji.com/mediawiki/index.php/%E5%BD%B9%E7%A8%AE%E8%A1%A8)（四暗刻条目）；RCR 规则书 4.2.2.3「三暗刻…注意：荣和的刻子算明刻」。
**实现要点**：判定暗刻数时，必须把「荣和补成的那一组刻子」降级为明刻；**自摸补成的那一组仍是暗刻**。这一条直接影响三暗刻/四暗刻的成立。

#### (7) 国士无双十三面 / 四暗刻单骑 / 大四喜 / 纯正九莲宝灯 的双倍役满认定

见 §1.7 表。补充细节：

- **国士无双十三面**：听牌时手牌为 13 种幺九牌各 1 张，听 13 面。
  - **振听**：天凤明确 `国士無双13面待ちは13牌振聴対象`（河里有任何幺九牌即 13 面全振听）；部分规则允许「十三面听时，现物以外的牌可荣和」→ 这是**分歧点**，`[待核实]` 各平台实现；主流平台（天凤）取「13 面全振听」。
  - **抢暗杠**：天凤明确「他家暗杠的牌不能和国士」（不可抢暗杠）；雀魂役种表「枪杠…（国士无双可以抢暗杠）」→ **两平台相反**。
- **纯正九莲宝灯**：九莲宝灯 9 面听形态（1112345678999 听 1-9），加倍与否见 §1.7。
- **大四喜**：有包牌；天凤为单倍，雀魂为双倍。
- **天和复合**：雀魂侧「天和 + 四暗刻单骑/国士十三面/纯正九莲 = 三倍役满」，`[待核实]`。

#### (8) 二杯口的「4 张同牌」形态

二杯口**允许** 4 张同牌（与七对子不同）。例：`1111m 2222m 3333m + 77m` 可拆为 111m+111m / 222m+222m / 333m+333m 两组一杯口 ×2 = 二杯口。
来源：[中文维基·二盃口](https://wiki.queji.com/mediawiki/index.php/%E4%BA%8C%E7%9B%83%E5%8F%A3)「并不像七對子那樣，和牌不能用4張同樣牌【例2】」。
而七对子**不允许**：`4 张同牌不能当作 2 组对子`（故「绿一色 + 七对子」「清老头 + 七对子」不可能成立）。

#### (9) 役满是否需要符数

**不需要。** 役满按固定点数结算（子 32000 / 亲 48000，双倍役满翻倍），符数不参与计算。
来源：[中文维基·符计算](https://wiki.queji.com/mediawiki/index.php/%E7%AC%A6%E8%A8%88%E7%AE%97)「國士無雙由於是役滿，計算得點時無需考慮符」；RCR 规则书同。
例外：**青天井规则**（不封顶、按 符×2^(番+2) 一路算下去）下需要计算役满的符；天凤/雀魂/雀姬均**不采用**青天井。

## 2. 符数计算

### 2.1 加符项总表

| 项 | 符数 | 备注 |

| 自摸 | **+2** | 门清/副露都加；**岭上开花也加 2 符**（天凤明确「嶺上ツモも2符加算」） |
| 听牌符：单骑 | **+2** | |
| 听牌符：嵌张（坎张） | **+2** | |

| 雀头符：三元牌 | **+2** | |
| 雀头符：自风牌 | **+2** | |

| 面子符：幺九暗刻 | **+8** | |

来源（三源一致）：

> ✅ 用户提出的数值「中张明刻 2 / 幺九明刻 4 / 中张暗刻 4 / 幺九暗刻 8；明杠 8/16，暗杠 16/32」**已核对为准确**。

### 2.2 符数上限与下限

- 理论最大 **110 符**（例：连风雀头 4 + 中明刻 4 + 1m 暗杠 32 + 南暗杠 32 + 底 20 + 门清荣和 10 = 102 → 110）。
  - 权威例证：[中文维基·符计算 牌例](https://wiki.queji.com/mediawiki/index.php/%E7%AC%A6%E8%A8%88%E7%AE%97)给出「底符20+门清荣和10+东连风雀头4+中明刻4+1m暗杠32+南暗杠32=102符→110符，计110符1翻（役牌中）」。
- 麻雀豆腐原文：「符は、最低でも20符、最大で110符が与えられる」（[来源](https://majandofu.com/rule-score-fu)）。

### 2.3 符数切上（切り上げ）

**规则**：所有加符项累加完毕后，**若个位不是 0，则向上取整到下一个 10**（不是四舍五入）。
例：32 符 → 40 符；38 符 → 40 符；102 符 → 110 符。

**关于「一律进位」还是「自摸时进位」的分歧（用户重点疑问）**：

| 说法 | 结论 |
|---|---|
| **主流与所有主流平台：一律进位**（荣和、自摸同样进位） | ✅ 采用 |
| 「只对一般形有效」（七对子不切上） | ✅ 七对子固定 25 符，不切上、不加任何附加符 |
| 「自摸才进位、荣和不进位」 | ❌ 未在任何主流规则/平台中发现此说法，**判定为误传** |

**佐证**：一般形的「底符 20 + 自摸 2 = 22 符」这一形态在实机上总是以 **30 符**出现（例：副露平和形自摸 30 符、无刻子门清自摸非平和形 30 符），说明切上确实作用在**自摸**上；若「自摸不进位」，这些牌都会变成 22 符，与所有平台/规则书不符。至于平和自摸，平台走的是「**直接把总符定为 20**，不先加 2 再谈进位」这条路径，与上面的切上规则并不冲突。
→ **最容易混淆的是「符数切上」与「点数切上」两件事**：符数进位到 10 是所有平台一致的；点数支付时进位到 100 也是所有平台一致的（见 §3.4）。真正存在分歧的是**切上满贯**（§3.3），不少人把「切上满贯」误记成「切上符」。

来源：[中文维基·符计算](https://wiki.queji.com/mediawiki/index.php/%E7%AC%A6%E8%A8%88%E7%AE%97)「符合计后，符个位不是0时：个位变0 十位+1」；麻雀豆腐「符は下一桁を切り上げ！」；RCR 规则书注解 2「手牌全部的符加总之后，取顶到整十」。

### 2.4 连风牌雀头：2 符还是 4 符（**真实分歧**）

| 规则 / 平台 | 连风牌雀头符 | 出处可信度 |
|---|---|---|
| **天凤（Tenhou）** | **4 符** | **高** — 官方手册原文：`連風牌は4符`（[tenhou.net/man/](https://tenhou.net/man/)） |
| **雀姬（雀姫）** | **4 符** | **高** — 中文维基雀姬规则页原文「连风牌雀头4符」 |
| **雀魂（Mahjong Soul）** | **4 符** `[待核实]` | **中** — 中文维基符计算页：「连风=W东，W南）**天凤&雀姬&雀魂=4符**，有些规则2符」；未取得雀魂官方页确认 |
| 一般线下规则 / 多数雀庄 / 关东标准 | **2 符** | **高** — 麻雀豆腐：「雀頭が連風牌の時は2符で計算するのが一般的ですが、こちらも一部のプロ団体や雀荘によっては4符と計算することがあります」 |
| 日本プロ麻雀連盟（JPML） | **4 符** | 高 — 麻雀豆腐编辑部在评论区明确：「日本プロ麻雀連盟というプロ団体は今でも4符で扱っています」 |

**给实现者的结论**：
- 默认值设为 **4 符**（与天凤/雀魂/雀姬三个主流线上平台一致）；
- 提供 `renfon_pair_fu: 2 | 4` 配置项。

**逻辑自洽性说明**：连风雀头 = 同时是自风与场风 → 若按「役牌雀头 +2」逐项相加则为 4 符；天凤系取 4 符即遵循此逻辑。

### 2.5 特殊固定符

| 情形 | 符数 | 规则 |
|---|---|---|
| **平和 + 自摸** | **固定 20 符** | 舍弃自摸的 2 符，换取平和 1 番（「ツモピン20符」）。天凤明确采用。 |
| **平和 + 荣和** | **30 符** | 20（副底）+ 10（门清荣和）= 30，两面听 0 符、顺子 0 符、非役牌雀头 0 符 |
| **七对子（荣和/自摸均同）** | **固定 25 符** | 无视其他一切加符项（不加门清荣和、不加自摸符、不加单骑符），**也不做切上** |
| **副露平和形（クイピンフ形）荣和** | **固定 30 符** | 底符 20 + 无门清荣和 + 全顺子 + 非役牌雀头 + 两面听 = 20 符 → 但按「最低 30 符」规则提升为 30 符。天凤/雀魂均如此；RCR 规则书注解亦列「非门清平和 → 20 符（底）」并另有最低限说明 |
| **副露平和形 + 自摸** | **30 符** | 20 + 2（自摸）= 22 → 切上 30 符。所以**副露平和形无论荣和自摸都是 30 符** |
| **国士无双** | 不计算 | 役满，符不参与 |

**关于「副露平和形 30 符」的实现口径**：可以理解为「平和在门清时算 1 番，副露时折算成 2 符」（[中文维基·符计算](https://wiki.queji.com/mediawiki/index.php/%E7%AC%A6%E8%A8%88%E7%AE%97)原文），也可以直接实现为「一般形总符 < 30 时一律抬到 30」。**后者的等价实现更安全**：唯一能出现总符 < 30 的一般形就是这种 20 符形。麻雀豆腐原文总结：「『ピンフツモ20符』と『七対子25符』以外は30符～と覚えましょう！！」

### 2.6 最低符数：20 / 25 / 30 分别出现在什么情况

| 最低符 | 出现条件 | 说明 |
|---|---|---|
| **20 符** | **仅**「平和自摸」（门清 + 4 顺子 + 非役牌雀头 + 两面听 + 自摸） | 也写作「ツモピン」。**不存在 20 符的荣和**；20 符时番数至少 2 番（平和 1 + 门清自摸 1） |
| **25 符** | **仅**七对子（荣和、自摸均可） | 门清限定，故至少 2 番（自摸时 3 番） |
| **30 符** | 其他**全部**一般形（含副露平和形荣和/自摸、以及所有含刻子的形） | 一般形的最小可能值 = 20（底）+ 2（自摸）= 22 → 切上 30 |

**注意**：不存在「20 符 1 番」「25 符 1 番」的合法和牌（见 §3.5 速查表用 `—` 表示）。

**「平和自摸不成立」的少数规则**（`ピンヅモなし`）：部分线下规则不承认平和与自摸复合，此时平和自摸只算门清自摸 1 番、30 符（副底 20 + 自摸 2 → 切上 30）。
来源：麻雀豆腐评论区编辑部答复（[来源](https://majandofu.com/rule-score-fu)：「ピンヅモなしルールでは…役は面前ツモ1翻のみとなり、符は30符」）。天凤、雀魂均**采用**平和自摸 20 符。

### 2.7 役满时是否计算符

**不计算。** 见 §1.8(9)。

## 3. 点数计算

### 3.1 基本点公式

```
基本点 = 符 × 2^(2 + 番)
```

> 指数里的 `2` 即「场ゾロ」（场棒），无条件附加的 2 番。**注意**：很多教学材料省略它，只写「符 × 4 × 2^番」（子）或「符 × 6 × 2^番」（亲）。两者等价：
> - 子家得点 = 基本点 × 4 = 符 × 4 × 2^番 × 2^2 = 符 × 4 × 2^(番+2)
> - 亲家得点 = 基本点 × 6 = 符 × 6 × 2^(番+2)
>
> 来源：[麻雀豆腐·点数計算 計算式と早見表](https://majandofu.com/rule-score-pointstable)；RCR 规则书 §4.3.1「基本点 = 符 × 2^(翻+2)」。

**基本点封顶**：`基本点 > 2000` 时一律取 2000（满贯）。5 番以上不再用公式，直接按番数定值。

### 3.2 满贯 / 跳满 / 倍满 / 三倍满 / 役满 的界限

| 名称 | 番数界限 | 基本点 | 子家荣和 | 子家自摸（子/亲） | 亲家荣和 | 亲家自摸（all） |
|---|---|---|---|---|---|---|
| （通常） | 1–4 番 | 符×2^(番+2)，封顶 2000 | 按表 | 按表 | 按表 | 按表 |
| **满贯** | **5 番**；或 1–4 番但基本点 > 2000（如 4 番 40 符 = 2560、3 番 70 符 = 2240） | 2000 | **8000** | 2000 / 4000 | **12000** | 4000 |
| **跳满** | **6–7 番** | 3000 | **12000** | 3000 / 6000 | **18000** | 6000 |
| **倍满** | **8–10 番** | 4000 | **16000** | 4000 / 8000 | **24000** | 8000 |
| **三倍满** | **11–12 番** | 6000 | **24000** | 6000 / 12000 | **36000** | 12000 |
| **累计役满（数え役满）** | **≥ 13 番** | 8000 | **32000** | 8000 / 16000 | **48000** | 16000 |
| **役满**（役满役） | 役满役 | 8000 | **32000** | 8000 / 16000 | **48000** | 16000 |
| **双倍役满**（平台相关，见 §1.7） | — | 16000 | **64000** | 16000 / 32000 | **96000** | 32000 |

来源：[中文维基·点数计算](https://wiki.queji.com/mediawiki/index.php/%E9%BB%9E%E6%95%B8%E8%A8%88%E7%AE%97) 的规则原文（含「飜＜6，得點＞8000時，得點=8000」「6飜或7飜時，得點=12000」…）；[麻雀豆腐](https://majandofu.com/rule-score-pointstable)；[天凤官方](https://tenhou.net/man/)（`数え役満は13翻以上`）。

### 3.3 切上满贯（4 番 30 符 / 3 番 60 符）—— **真实分歧**

**切上满贯判定条件**：基本点 = 符 × 2^(番+2) 恰好 = **1920**（即 30 符 4 番、60 符 3 番），与满贯的 2000 只差 80 点，故部分规则「切上」到 2000 直接算满贯。

**实现建议**：`kiriage_mangan: boolean` 配置项，默认 `false`（与天凤段位战、雀魂一致）；开启时把 `(30符,4番)` 与 `(60符,3番)` 的基本点抬到 2000。

### 3.4 支付方式与零头进位

| 情形 | 支付方式 |
|---|---|
| **子家荣和** | 放铳者支付 **基本点 × 4** |
| **子家自摸** | 亲家支付 **基本点 × 2**；另两个子家各支付 **基本点 × 1** |
| **亲家荣和** | 放铳者支付 **基本点 × 6** |
| **亲家自摸** | 三个子家各支付 **基本点 × 2**（合计 基本点 × 6，故亲家自摸总收 = 亲家荣和） |

**进位（零头）规则**：
- 每一笔**实际支付额**都**向上进位到 100 点**（不是四舍五入）。
- **谁承担零头**：**支付方各自承担**。即子家自摸时，「亲付基本点×2」和「子付基本点×1」**分别各自进位到 100**，而不是先加总再进位。
- 因此会出现**自摸总收 > 荣和收入**的现象。例：亲家 30 符 3 番（荣和 5800）→ 自摸时每子付 ceil(960×2 /100)×100 = 2000 → 共收 **6000**（比荣和多 200）。
- 反例说明：子 25 符 3 番，基本点 800 → 子付 800（已整）、亲付 1600 → 荣和 3200，自摸 800+800+1600 = 3200（相等）。

来源：[麻雀豆腐](https://majandofu.com/rule-score-pointstable)「割り算をして、点数の下二けたが端数となった場合は切り上げとなります」「麻雀の点数には10点単位がなく、端数が出た場合には切り上げて計算します…よって、ユーザー様の仰る通り、ロンよりツモアガりの方が点数が多くもらえるケースがあります」；RCR 规则书 §4.3.1「…取顶到百」。

### 3.5 本场（積み棒）与立直棒

| 项 | 规则 |
|---|---|
| **本场 300 点** | 每一本场，和牌者额外获得 **300 点** |
| **荣和时** | 300 × 本场数，**由放铳者全额支付** |
| **自摸时** | 300 × 本场数，**由三家分摊，每家各付 100 × 本场数** |
| **立直棒（供托）1000 点** | 每根 1000 点，**全部归和牌者**（多家和牌时按平台规则，天凤为「上家取り」；和牌者收全部已供托的立直棒） |
| **流局时** | 立直棒留在场上累积到下一局 |
| **终局时** | 天凤：`終了時の供託はトップ取り`（剩余供托归一位）；雀魂同（「游戏结束时，由一位获得全部场供」） |

## 4. 实现陷阱（Top 10）

> 每条给出「常见错误」与「正确做法」。

### ① 平和自摸的符
- **常见错误**：把平和自摸算成 20 + 2（自摸符）= 22 → 切上 30 符，于是打出 30 符 2 番（子 2000）而不是 20 符 2 番（子自摸 400/700）。
- **正确做法**：**只要成立平和（门清 + 全顺子 + 非役牌雀头 + 两面听）且为自摸，直接把最终符定为 20**（`if pinfu && tsumo: fu = 20`），跳过自摸 2 符与一切切上。子家 2 番 20 符自摸 = 400/700，亲家 = 700 all。

### ② 连风牌雀头符数
- **常见错误**：默认按「役牌雀头 +2」算 2 符；或反过来在只有自风/只有场风时也加 4 符。
- **正确做法**：雀头符 = `(三元牌? 2:0) + (自风? 2:0) + (场风? 2:0)`，**连风牌时两项各加 2 = 4 符**（天凤/雀魂/雀姬默认）。同时**独立实现 `renfon_pair_fu` 开关**以支持 2 符规则集。
  注意：连风雀头**不产生任何役**，只影响符，且会**破坏平和**（雀头是役牌）。

### ③ 一杯口 / 二杯口 / 七对子的三方纠缠
- **常见错误**：二杯口 + 一杯口一起算（3+1=4 番）；或七对子与二杯口一起算（2+3=5 番）；或把 `1111m` 当作七对子的 2 对。
- **正确做法**：
  - 相同顺子组数 = 1 → 一杯口 1 番；= 2 → 二杯口 3 番，**不再加一杯口**；
  - 二杯口与七对子**互斥二选一**，按高点法**比较实际总点数**而非只看番数。多数情况下二杯口胜（例：二杯口 3 番 40 符荣和 **5200** vs 七对子 2 番 25 符荣和 **1600**）；理论上存在七对子胜的构型（七对子可带宝牌/立直/自摸等叠加，且二杯口构型若无法成立更高符），故必须真的算点数再比；
  - 七对子判定时，**4 张同牌不算 2 对**（直接判七对子不成立）；
  - 二杯口**允许** 4 张同牌（`1111 2222 3333 + 雀头` 成立）。

### ④ 切上满贯
- **常见错误**：把 4 番 30 符 / 3 番 60 符（基本点 1920）直接当满贯 → 子 8000 / 亲 12000。
- **正确做法**：默认**不切上** → 4 番 30 符（子）= 7700 荣和 / 2000·3900 自摸；（亲）= 11600 / 3900 all。提供 `kiriage_mangan` 开关（天凤**雀荘战**、M 联赛、部分团体赛为 `true`；天凤**段位战**、雀魂、RCR 为 `false`）。
  同时注意：**真正的满贯界限**是「基本点 > 2000」——4 番 40 符（2560）、3 番 70 符（2240）等是**按公式算出来就超过 2000**，属于满贯，这与切上满贯是两回事，不要混为一谈。

### ⑤ 自摸零头进位：谁承担零头
- **常见错误**：先算「子家自摸总额」再除以 3 分摊；或对总额进位后分摊。
- **正确做法**：**分别计算每一笔支付额并各自向上进位到 100 点**：
  - 子家自摸：`亲付 = ceil100(基本点 × 2)`，`子付 = ceil100(基本点 × 1)`（两个子家各付这么多）；
  - 亲家自摸：`每子付 = ceil100(基本点 × 2)`；
  - `ceil100` 是**向上取整**（1900 → 1900；1280 → 1300；650 → 700），不是四舍五入。
  由此会出现「亲家 30 符 3 番自摸收 6000 > 荣和 5800」这类**自摸比荣和更赚**的情况，这是正确行为，不是 bug。

### ⑥ 荣和补成的刻子按明刻计
- **常见错误**：双碰听荣和时，把和牌张补成的那组刻子算暗刻 → 错判三暗刻/四暗刻。
- **正确做法**：`荣和完成的刻子 = 明刻`；`自摸完成的刻子 = 暗刻`。影响：
  - 双碰听荣和 → 四暗刻**不成立**（只剩 3 暗刻，应为「三暗刻 + 对对和」）；
  - 符数：该刻子按**明刻**计符（中张 2 / 幺九 4），而不是暗刻的 4/8。
  天凤官方明确此条。

### ⑦ 副露平和形（クイピンフ形）的最低 30 符
- **常见错误**：副露后底符 20、无门清荣和、全顺子、非役牌雀头、两面听、荣和 → 算成 20 符，进而误用 20 符行（该行只有平和自摸才有意义）。
- **正确做法**：加一条「一般形最低 30 符」的钳制：`if 牌型为一般形 && 总符 < 30: 总符 = 30`。这样荣和 20→30、自摸 20+2=22→30，统一处理。
  **注意不要**把这条钳制应用到七对子（七对子恒 25 符）和国士无双（役满不算符）。
  **也注意**：不要用「先判断是否平和，若不是则 +2」这类间接写法来代替钳制——副露平和形既不成立平和、也不该只拿 22 符。

### ⑧ 幺九牌的判定范围（面子符与断幺九）
- **常见错误**：把字牌排除在「幺九」之外，导致字牌暗刻只加 4 符（应为 8 符）。
- **正确做法**：「幺九牌」= 数牌 1、9 + **全部字牌**（东南西北白发中）。所以：中暗刻 8 符、发暗杠 32 符。断幺九要求**不含任何字牌**。
  三麻特例：**拔北后，被拔的北不计入断幺九**（天凤/雀魂三麻均有此规则）。

### ⑨ 符数切上 vs 点数切上的混淆
- **常见错误**：以为「符数只在自摸时进位」；或对符数做四舍五入（34 → 30）。
- **正确做法**：
  - **符数切上**：一律**向上取整**到 10（32→40、38→40、102→110），荣和自摸都做（但平和自摸/七对子/役满是例外，直接取固定值）；
  - **点数切上**：每笔支付额**向上取整到 100**（见 ⑤）。
  两个切上是不同层次，别互相套用。

### ⑩ 役满倍数与「役满不复合非役满役」
- **常见错误**：四暗刻 + 对对和一起算；九莲宝灯 + 清一色一起算；把天凤的四暗刻单骑当成双倍役满（照抄雀魂规则）；或反过来把雀魂的国士十三面算成单倍。
- **正确做法**：
  - 役满役**之间可以复合**（如大四喜 + 字一色 = 2 倍役满）；
  - 役满役**不与任何非役满役复合**，也不与宝牌/赤宝/里宝复合（「役满以上不再加点」）→ 检测到役满后，直接短路返回役满点数（**天凤的官方用词更精确：役满役之间可复合，但役满役与役满役以外的役、以及悬赏牌不复合**）；
  - **役满倍数做成配置表**：天凤 = 全 1 倍（官方明文 `すべてシングル役満`）；雀魂 = {四暗刻单骑、国士无双十三面、纯正九莲宝灯、大四喜} = 2 倍；
  - **包牌**单独实现：大三元/大四喜有包（天凤、雀魂），**四杠子无包**；包牌时自摸全包、荣和半包，本场棒也归包牌者（天凤）。

## 7. 延伸阅读：待补的三麻规格

本次调研未覆盖三人麻将（三麻）的独立差异，已知需要在单独文档中处理：
- **自摸损**（雀魂三麻明确「有自摸损」）：子家自摸时结构变化，收入低于理论值；
- **拔北**：算鸣牌（消除一发/地和/九种九牌/两立直）、可被抢北和（抢北和不算役）、拔北自摸算岭上开花、被拔的北不计入断幺九、北作面子时算客风、拔北后该北作宝牌；
- **不使用 2m–8m**；宝牌表示「一万」对应「九万」（「九万」对应「一万」）；
- **起始/返点 35000 / 40000**，顺位马 +20 / 0 / −20；
- 岭上牌 8 枚。
