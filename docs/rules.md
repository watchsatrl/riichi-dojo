## 1. 牌的构成

### 1.1 牌种、张数与索引

**34 种 × 4 张 = 136 张**（四麻全用）；**三麻不使用 2m–8m**（剔除 7 种 × 4）→ **108 张**。`[二手]` 萌娘百科雀魂条目

```
花色顺序: m(万) → p(筒) → s(索) → z(字)
索引方案（推荐）: m 0..8 | p 9..17 | s 18..26 | z 27..33
z 内部: 1z=东 2z=南 3z=西 4z=北 5z=白 6z=发 7z=中
```

不同资料的 `z` 内部编号不一致，**实现时只依赖常量表，不要依赖算术关系**。

**宝牌指示牌的循环顺序**（§3.5 用到）：数牌 `1→2→…→9→1`（同花色内循环）；风牌 `东→南→西→北→东`；三元牌 `白→发→中→白`。`[二手]` 中文维基日本麻將規則

### 1.2 赤牌（赤宝牌 / 赤ドラ）

| 规则集 | 赤牌枚数与位置 |
|---|---|
| **雀魂四人段位场（默认）** | **3 枚**：赤 5 万、赤 5 筒、赤 5 索**各 1 张** `[二手]` |
| 雀魂友人场 | 可选「无赤／三枚赤／四枚赤」 |
| 天凤四人段位战 | **3 枚**各 1 张 `[一手]`「赤ありルールでの枚数：各1枚」（2007-07-16 前为 4 枚，07-17 起改 3 枚） |
| JPML A／WRC | **无赤牌** `[一手]`（WRC：red fives…are not used） |
| WRC-R（JPML 运营） | 5 万/5 筒/5 索 各 1 枚（作ドラ） |

> **开关** `aka_dora`：雀魂 `{5m:1,5p:1,5s:1}` ｜ 备选 `{}`、`{5m:1,5p:2,5s:1}` ｜ 天凤同雀魂 ｜ 竞技 `{}`

**实现要点**：① 赤 5 与普通 5 **是同一牌种**，只在**计番**时区分，故手牌表示需保留「这一张是赤的」属性；② 赤牌**计 1 番/张**，属悬赏役，不计入起和番（§7.4）；③ 赤 5 作为面子/雀头时牌种仍是 5，不影响断幺九、三色、一气等判定；④ 三麻只有赤 5 筒与赤 5 索（§13）。

### 1.3 牌的分类

| 分类 | 定义 | 用途 |
|---|---|---|
| **老头牌** | 数牌 `1`/`9`（6 种） | 纯全带、清老头 |
| **幺九牌** | **老头牌 + 全部字牌** = **13 种** | 断幺九、混全带、混老头、国士、九种九牌、流局满贯、符数的幺九加倍 |
| **中张牌** | 数牌 `2..8`（21 种） | 符数的中张档 |
| **风牌** | `1z` 东 `2z` 南 `3z` 西 `4z` 北 | 场风、自风 |
| **三元牌** | `5z` 白 `6z` 发 `7z` 中 | 役牌 |
| **役牌** | **三元牌 ∪ 场风牌 ∪ 自风牌** | 役牌役、雀头符、平和的否定条件 |

**★ 最容易错的一条：字牌全部属于「幺九牌」。**

```js
const isYaochu = (t) => isHonor(t) || rank(t) === 1 || rank(t) === 9;
// 因此：中暗刻 = 8 符（不是 4 符）；断幺九要求不含任何字牌
```

`[二手]` 凛上开花 wiki「幺九=19萬19索19筒東南西北白發中」。**三麻特例**：拔出的北不计入断幺九（§13.5）。

### 1.4 本局的风（场风与自风）

**场风** = 东场 `1z`／南场 `2z`／西场 `3z`／北场 `4z`。
**自风** = 本局庄家 `1z`（东家）；自庄家起**逆时针**依次 `2z` 南家、`3z` 西家、`4z` 北家。
**连风牌** = 自风 == 场风；**客风牌** = 既非场风也非自风。

「东南西北」与玩家物理座位**无关**，只由本局谁是庄家决定。同一玩家连庄时自风不变，轮庄后递变。

**天凤特例（易错，雀魂同样适用）** `[一手]`：东风战进入南场后场风变为南，`1z`（东）**不再算场风役牌**（天凤 FAQ「東風戦で南入した場合は、場風の「東」は1飜になりません」）。

## 2. 局与场

### 2.1 场的结构

**东风战** = 东 1–4 局（4 局）；**半庄战/东南战** = 东 1–4 + 南 1–4 局（8 局）——两者雀魂段位场均可选。一庄战（16 局）、东北战、东东战雀魂**不提供**。`[二手]` 萌娘百科雀魂条目「目前段位場中提供東風戰與半莊戰兩種模式」

局命名格式 `{场风}{局数}局`，连庄时追加 `{m}本场`（如「东二局3本场」）。

### 2.2 亲家与子家

| 称呼 | 定义 | 支付责任 |
|---|---|---|
| **亲家（庄家）** | 本局庄家，自风恒为 `1z` | 支付额 ×2；和牌得点 ×1.5 |
| **子家（闲家）** | 其余 3 人，自风依次 `2z`/`3z`/`4z` | 支付额 ×1 |

### 2.3 起家与座次

**起家**：开局随机决定（线上由服务器随机）`[推定]`。
**座次顺序**：**逆时针** = 打牌顺序；起家为东一局东家，其下家为南家，依次西家、北家。
**同点顺位**：终局同点时按**东一局座次**决定（东家 > 南家 > 西家 > 北家）。`[二手]` 萌娘百科雀魂条目

> **开关** `tie_break_by_seat`：雀魂/天凤/雀姬 `true`（`[一手]` 天凤「終了時に同点の場合は東1局の風順で順位を決定」）｜ WRC `false`（同点者均分顺位点）

### 2.4 本场（本場 / 積み棒）

| 项 | 值 |
|---|---|
| **四麻本场 1 根** | **300 点** `[推定]`（依据见下） |
| **三麻本场 1 根** | **200 点** `[二手]` 萌娘百科雀魂条目三麻「本場棒1根200點」 |
| 荣和时 | `300 × 本场数`，由**放铳者全额支付** |
| 自摸时 | `300 × 本场数`，**三家分摊，每家各付 `100 × 本场数`** |
| 对照 | 天凤四麻 300 ／ JPML 300 ／ WRC 300 ／ 天凤雀荘战 四東1500・四南300・三東1000・三南200 `[一手]` |

**`[推定]` 依据链**：萌娘百科雀魂条目在**四麻段完全未写**本场值与罚符值，而在三麻段以「仅标注不同部分」的写法写明 200/2000；四麻的 300/3000 由「三麻 = 差异值」＋日麻通例反推。**数值本身四套规则一致，但缺雀魂官方直接表述** → 附录 C-1。

> **开关** `honba_value`：雀魂四麻 `300` ｜ 雀魂三麻 `200` ｜ 天凤 `300` ｜ 竞技 `300`

```
本场累加与清除:
  庄家和牌 → +1（连庄）        庄家听牌流局 → +1（连庄）
  庄家不听流局 → 清零，轮庄      子家和牌 → 清零，轮庄
  途中流局 → +1（连庄）
```

### 2.5 供托（供託 / 立直棒）

| 项 | 规则 |
|---|---|
| 立直宣言费 | **1000 点/次**，宣言时立即支付到桌上成为供托 |
| 和牌时归属 | 和牌者取得**全部**已供托的立直棒 |
| **多家和牌时** | 由**头跳家**取得（§6.5） |
| 流局时 | **留场**累积到下一局 |
| **终局时** | **由一位（第一名）获得全部场供** `[二手]` 萌娘百科雀魂条目 |
| 立直宣言牌放铳 | 立直**不成立**，**不收宣言供托**（1000 点**退还**） |

> **开关** `riichi_stick_on_final`：雀魂/天凤 `top_takes_all`（`[一手]`「終了時の供託はトップ取り」）｜ JPML `void`（「オーラス終了時のリーチ棒は供託となる」，**无人取得**）｜ WRC `void`（Nobody collects them）

### 2.6 连庄条件（完备表）

| 结束原因 | 是否连庄 |
|---|---|
| 庄家和牌 / 子家和牌 | **连庄** / 轮庄 |
| 荒牌流局 + **庄家听牌** | **连庄** `[二手]`「不聽流局下莊，聽牌連莊」 |
| 荒牌流局 + 庄家不听 | 轮庄 |
| **途中流局**（四种全部） | **连庄** `[二手]`「途中流局連莊」 |
| **流局满贯成立** | **若庄家听牌则连庄**（与普通荒牌流局同条件） |
| **多家和牌中含庄家** | **连庄** `[二手]`「莊家和牌則連莊」 |

**「形式听牌」算听牌**（§6.4），故庄家形式听牌也能连庄。`[二手]` 萌娘百科雀魂条目「有形式聽牌，不承認虛聽」

## 3. 配牌与摸打

### 3.1 配牌与牌山

庄家起手 **14 张**，子家 **13 张**。牌山 = 17 墩 × 2 张 × 4 列 = 136 张；其**王牌 14 张**（7 墩）不用于常规摸牌，**岭上牌** = 王牌中最靠近开门位置的 **2 墩 = 4 张**（三麻 **8 张**）；**宝牌指示牌** = 开门位置起第 **3** 墩的上张，**里宝牌指示牌** = 与它**同一墩的下张**。可摸牌（壁牌）= 136 − 14 = **122 张**。`[二手]` 中文维基日本麻將規則

### 3.2 摸打循环与「一巡」

```
初始: 庄家 14 张，子家各 13 张，庄家先行
循环:
  当前玩家:
    1. 先摸 1 张（杠/拔北后则摸岭上牌）
    2. 处理摸牌后可宣告的动作: 自摸和牌 / 暗杠 / 加杠 / 立直 / 九种九牌 / 拔北
    3. 打出一张牌
    4. 其他三家依次判断: 荣和 > 碰/大明杠 > 吃（§4.1）
       有人鸣牌 → 该玩家成为当前玩家，跳到步骤 3（不再摸牌）
       无人鸣牌 → 当前玩家切换为下家（逆时针），回到步骤 1
终止: 有人和牌 / 壁牌摸完（荒牌流局）/ 途中流局条件成立
```

**「一巡」** = 从自己摸牌到下一次自己摸牌之间的过程。一发、两立直、地和、九种九牌等判定均依赖它。

### 3.3 王牌与岭上牌

岭上牌**仅在开杠（或三麻拔北）后**补入手牌（摸 1 张然后打 1 张）。四麻 **4 张** → 一局中开杠最大 **4 次**；第 5 次杠**不得开出**；四麻第 4 次杠触发四槓散了判定（§10.5.4）。三麻 **8 张** `[二手]` 萌娘百科雀魂条目三麻「嶺上牌共有8張」。`[二手]` 中文维基「由于岭上牌仅有4张，因此一局中开杠的最大数目也被限制为4次」

### 3.4 海底牌与河底牌

**海底牌** = 牌山**最后一张可摸的牌**（壁牌第 122 张）→ 海底摸月（自摸）；**河底牌** = 海底牌被打出后形成的那张弃牌 → 河底捞鱼（荣和）。三条规则：① **不可以鸣海底牌**（吃/碰/大明杠均不可）`[二手]` 萌娘百科雀魂条目「不可以鳴海底牌」／`[一手]` 天凤「海底牌は鳴けない」；② **河底牌可以被荣和**，但之后不再有摸牌；③ 海底摸月与岭上开花**不复合**（出现海底牌时岭上牌已不存在）。

> **开关** `cannot_call_haitei`：雀魂／天凤／竞技均 `true`（三套一致）

### 3.5 宝牌（悬赏牌 / ドラ）

**指示牌 → 宝牌**：`doraFrom(indicator)` = 数牌同花色 `rank+1`（9→1）；风牌东南西北循环；三元牌白发中循环。
**三麻特例** `[一手]`：`1m → 9m`、`9m → 1m`（万子门只有两张，§13.3）。

| 种类 | 翻出时机 | 生效条件 |
|---|---|---|
| **表宝牌** | 每局配牌时 | 常时 |
| **杠宝牌** | 有人开杠后（时机见下） | 常时 |
| **里宝牌** | **仅在立直者和牌后** | 需立直 |
| **杠里宝牌** | 杠宝牌指示牌同墩下张，立直者和牌后 | 需立直 + 当场开过杠 |
| **赤宝牌** | 不需要指示牌 | 常时（§1.2） |
| **拔北宝牌** | 三麻专用 | §13.5 |

**杠宝牌的翻出时机**（雀魂与天凤均为「后翻」）：**暗杠立即翻出**；**明杠／加杠要等摸到岭上牌并打出 1 张牌之后**才翻出。`[二手]` 萌娘百科雀魂条目「暗槓直接翻槓寶牌，明槓或加槓情況下在摸到嶺上牌並打出一張牌後翻槓寶牌」；`[一手]` 天凤「カンドラは、暗槓は即乗り、明槓/加槓は後めくり」

> **开关** `kandora_timing`：雀魂／天凤段位战 `ankan_immediate_open_late` ｜ 天凤雀荘战 `immediate_all` ｜ 雀姬 `immediate_all`（`[二手]`「开杠立刻翻开悬赏表示牌」）

**计番**：每张宝牌 **+1 番**，可累计（多张、多指示牌指向同一牌种都累计）；**宝牌不计入起和番**（无役时即使持有宝牌也不能和牌，§7.4）；宝牌**计入**满贯/跳满界限与累计役满的 13 番门槛；**役满时宝牌不加算**（§7.7）。`[二手]` 中文维基「由宝牌得到的翻数只能用来胡牌后计翻，而不能作为和牌所需的翻数」

## 4. 鸣牌

### 4.1 优先顺序与并发处理

```
荣和  >  碰 / 大明杠  >  吃
```

同级冲突（两家都要碰）按**发声顺序**（线上按响应时间先后）。**荣和优先于一切副露** → 大明杠与荣和冲突时大明杠不成立，**不产生杠宝牌**，也不计抢杠。`[二手]` 中文维基日本麻將規則「一般情况下副露按照 (胡牌) > 碰牌/大明杠 > 吃牌 的顺序进行」

### 4.2 吃 / 碰 / 杠的成立条件

| 动作 | 谁能做 | 成立条件 | 字牌 | 破坏门清 | 可被抢杠 |
|---|---|---|---|---|---|
| **吃（チー）** | **仅下家** | 手牌中有同花色可组成顺子的两张：`x-2,x-1`／`x-1,x+1`（嵌张）／`x+1,x+2` | **不能吃** | **是** | 否 |
| **碰（ポン）** | **任意一家** | 手牌中有该牌的**对子**（2 张） | **可以碰** | **是** | 否 |
| **暗杠** | 自己 | 手牌中同一牌种 **4 张** | — | **否**（仍门清） | 正常不可；**雀魂：国士可抢暗杠**（§6.6） |
| **大明杠** | 任意一家 | 手牌中有该牌**暗刻（3 张）**，别家打出第 4 张 | — | **是** | **否** |
| **加杠** | 自己 | 自己**碰过**该牌，之后摸到第 4 张 | — | 是（本已副露） | **是**（§6.6） |

动作序列：**吃/碰** = 喊牌 → 公开手牌 2 张并连同鸣入牌横置放桌面右侧 → **打出一张牌**（不摸牌）；**杠** = 喊「杠」→ 公开 4 张（暗杠：中间或两端两张牌背朝上以区别）→ 摸 1 张岭上牌 → 打出一张牌。`[二手]` 中文维基日本麻將規則
**三麻**：**不可以吃牌** `[二手]` 萌娘百科雀魂条目三麻；`[一手]` 天凤「チーはできない」。
**鸣牌后**：被鸣的牌打出者**跳过**，鸣牌者成为当前玩家（不摸牌，直接打牌）。

**杠的副作用清单（每一条都必须实现）**：

| 副作用 | 说明 |
|---|---|
| 增加 1 次岭上摸牌 | 岭上牌 4 张 → 最多 4 次杠 |
| 翻出杠宝牌指示牌 | 时机见 §3.5 |
| 可能成立岭上开花 | 岭上摸牌后自摸（计自摸 2 符，§8.5） |
| 可能成立三杠子／四杠子 | 同一人的杠数 |
| **可能触发四杠散了** | 全场第 4 次杠（§10.5.4） |
| **破坏门清** | 仅大明杠与加杠；**暗杠不破坏** |
| **消除「一发」** | 任何杠（含暗杠）都打断一发巡（§5.5） |

### 4.3 食替禁止的准确边界

**定义**：**食替（喰い替え）** = 鸣牌后用鸣入的牌能组成的**同一组面子中的另一张牌**立即打出。**雀魂四人/三人段位场均「无食替」（禁止）** `[二手]` 萌娘百科雀魂条目「有食斷、有後付、**無食替**」

| 情形 | 是否禁止 | 说明 |
|---|---|---|
| 手牌 `45m` 吃 `3m` 成 `345m`，立即打 `6m` | **禁止** | 筋替（`345`/`456` 是同一顺子的两种取法） |
| 手牌 `45m` 吃 `6m` 成 `456m`，立即打 `3m` | **禁止** | 同上（反向） |
| 手牌 `45m` 吃 `3m`，立即打 `2m` | **允许** | `2m` 与 `345m` 不构成任何同一顺子 |
| 手牌 `13p` 吃 `2p` 成 `123p`，立即打 `2p` | **禁止** | **现物替**：打出刚鸣入的同一张牌 |
| 手牌 `23p` 吃 `1p` 立即打 `4p` ／ 吃 `4p` 立即打 `1p` | **禁止** | 筋替 |
| 手牌 `22p` 碰 `2p`，立即打 `2p` | **禁止** | 现物替 |
| **经过一巡之后再打出上述牌** | **允许** | 「喰い替えになるような牌でも、一巡置けば切る事ができる」 |

`[二手]` 麻雀ローカルルールWiki「喰い替え」；`[二手]` 凛上开花 wiki 简明规则；`[一手]` WRC §5.4 明文列举两种

```js
function isKuikae(meld, discardTile) {
  if (meld.type === 'chi') {
    return discardTile === meld.tile                                   // 现物替
        || (sameSuit(discardTile, meld.tile)
            && (rank(discardTile) === meld.startRank - 1
             || rank(discardTile) === meld.startRank + 3));            // 筋替
  }
  if (meld.type === 'pon') return discardTile === meld.tile;           // 现物替
  return false;   // 大明杠后不可能构成食替（4 张无法组成两组同顺子）
}
// 只限制「鸣牌后的那一次打牌」。自己下一次摸牌后再打即解除。
```

> **开关** `kuikae_allowed`：雀魂／天凤／竞技均 `false`（三套一致，边界也一致）

|---|---|---|

## 5. 立直

### 5.1 立直宣言的条件

```
canDeclareRiichi(player):
  return player.menzen                        // ① 门清（暗杠不影响）
      && player.isTenpai                      // ② 听牌（含形式听牌）
      && player.score >= 1000                 // ③ 点数 ≥ 1000（恰好 1000 可以）
      && remainingDrawableTiles() >= 4        // ④ 剩余可摸牌 ≥ 4
      && !player.riichiDeclared;              // ⑤ 本局尚未立直
// 时点：只能在自己摸牌后、打牌前宣言（宣言牌即本次打出的牌）
```

`[二手]` 萌娘百科雀魂条目「立直宣言必須要在1000點及以上，且剩餘牌大於等於4張時才可發出」。边界细节：门清 = 未吃未碰未大明杠未加杠，**暗杠后仍可立直**；听牌**包括形式听牌**；**恰好 1000 点可以**（支付后剩余 0 点，0 点继续游戏，§12.2）；剩余牌指**牌山剩余可摸牌数 ≥ 4**。

> **开关** `riichi_min_score`：雀魂／天凤／竞技均 `1000` ｜ `riichi_min_tiles_left`：雀魂 `4` ｜ WRC `4`
> **★ 重要来源分歧**：**天凤**的条件是「得点 1000 点以上**且还有下一次摸牌机会**」（`[一手]`「ツモ巡がある場合」），与「剩余可摸牌 ≥ 4 张」是**两个不同判据**，在「剩余 4 张但已轮不到自己摸」时结论相反 → 附录 C-2。

### 5.2 立直宣言牌放铳的处理（燕返）

`[二手]` 萌娘百科雀魂条目「立直宣言牌放銃（燕返）的情況下，算立直不成立，不收宣言供託」；`[一手]` 天凤「リーチ宣言牌で放銃した場合は供託料は発生しない」。**注意**：此处「燕返」是该情形的别称，与**古役「燕返」**（[yaku.md](yaku.md) §6）不是同一件事。

### 5.3 立直后的限制

允许：自摸和牌／荣和／暗杠（受限，§5.4）。禁止：吃／碰／大明杠／加杠／拔北（三麻）。
立直后手牌**锁定**：摸到的牌若不能和牌必须打出（不得改变手牌构成），除非能进行合法暗杠。

### 5.4 立直后暗杠的限制

### 5.5 一发（一発）

成立窗口 = 立直宣言后、**一巡内**和牌；打断条件 = 期间**任何**吃/碰/杠（含暗杠）/**拔北**（三麻）；**与岭上开花、海底摸月不复合**；**与抢杠可复合**，但仅限**连续杠的第 1 次** `[一手]`；番数 **1 番**，属**悬赏役**，**不计入起和番**（§7.4）。
**「纯正巡消し」精确时机** `[一手]`：一般情况在鸣牌**发声与和牌打诊之后、岭上摸牌之前**；加杠（抢杠）同理（仅限加杠）；三麻拔北同理；**连续加杠的第 2 次起不再计一发**。

### 5.6 两立直（双立直）

**第一巡**（自己第一次打牌之前）即宣告立直，且此前**无任何吃/碰/杠/拔北** → **2 番**（门清限定）。**只计两立直，不再加立直 1 番**：`const riichiHan = isDoubleRiichi ? 2 : 1;`。一发窗口与普通立直相同。
**注意**：两立直属**役**（计入起和番），一发属**悬赏役**（不计入）——这在 2 番缚/4 番缚下会直接改变能否和牌。

### 5.7 立直棒的归属

和牌者取得全部供托（每家 1000 点）；**多家和牌时由头跳家取得**（§6.5）`[二手]` 萌娘百科雀魂条目「若多家和牌，場供及場上的立直棒由頭跳家獲得」；流局**留场**累积；终局**由一位获得全部场供**（雀魂）；JPML/WRC 为**无人取得**（§2.5）。

## 6. 和了判定

### 6.1 和牌形式（三种，互斥）

**① 标准形**：4 组面子 + 1 组雀头 = 14 张。面子 ∈ {顺子（3 张连续同花色数牌）, 刻子（3 张同牌种）, 杠子（4 张，含明暗）}；雀头 = 2 张同牌种。张数校验：**杠子按 3 张计入面子**（第 4 张在杠区）；副露 n 组时听牌张数 = `13 − 3n`。

**② 七对子形**：**7 组对子**，共 14 张；**7 组对子的牌种必须互不相同**（4 张同牌不可拆成 2 对）；**门清限定**。`[二手]` 凛上开花 wiki「對子=7（四張牌不能當作2組對子）」

由该约束直接得到的结论（必须写进实现）：

| 组合 | 是否成立 | 理由 |
|---|---|---|
| 字一色 + 七对子 | **成立** | 字牌恰 7 种 `[一手]` 天凤「七対子の字一色あり」 |
| 混老头 + 七对子 | **成立** | 幺九牌有 13 种 ≥ 7 `[二手]` 凛上开花 wiki |
| 绿一色 + 七对子 | **不成立** | 绿一色可用牌种仅 6 种，凑不出 7 组互不相同的对子 `[二手]` 中文维基七對子 |
| 清老头 + 七对子 | **不成立** | 老头牌仅 6 种 |

**③ 国士无双形**：**13 种幺九牌各 1 张 + 其中任一种再 1 张**，共 14 张；**门清限定**；不计符数（役满）。**国士无双十三面** = 听牌时手牌为 13 种幺九牌各 1 张（尚未成对），听 13 面 = **双倍役满**（雀魂）。

### 6.3 振听（振聴 / フリテン）

任一成立即**不能荣和**，但**可以自摸**：

| # | 情形 | 触发条件 | 解除条件 | 持续 |
|---|---|---|---|---|
| ① | **舍牌振听** | 自己**牌河中**存在自己听的牌 | 变换手牌使当前听牌集合不再含牌河中的牌 | 直到解除或本局结束 |
| ② | **同巡振听** | 别家打出的牌是自己的和牌张但**见逃**（或无法和） | **自己切牌后解除** | 一次切牌 |
| ③ | **立直振听** | **立直后**见逃了他家和牌张 | **不可解除** | 直到本局结束 |

**舍牌振听只判定牌河中的牌** `[二手]` 萌娘百科雀魂条目「振聽只判定牌河中的牌。（加槓、拔北等不適用）」；`[一手]` 天凤「フリテンは河に捨てられた牌でのみ判定」

| 内容 | 是否计入舍牌振听 |
|---|---|
| 自己正常打出的牌 | **计入** |
| 被别家**鸣走**的自己的舍牌 | **计入**（`[一手]` 天凤 FAQ「被鳴走的牌也可以構成振聽」） |
| **加杠**被抢的那张牌 / **拔北**拔出的北 / 暗杠的 4 张 | **不计入** |

**同巡振听的解除（雀魂口径）**：**只有自己切牌才清除**；他人鸣牌（逆巡副露）**不清除**（`[一手]` 天凤「同巡振聴の解消は打牌時、逆巡副露では解消しない」）。
**★ 振听是「全听牌封锁」而不是「只封锁那一张」** `[二手]` 中文维基「无法荣和不仅意味着无法荣和导致振听的一张牌，而是所有可能荣和的牌均无法荣和」。
**「和牌放弃」的同巡振听（含抢杠）** `[一手]` 天凤「和了放棄(搶槓を含む)後は同巡フリテンとなり、次の自分のツモ番までロン和了できない」。
**形式听牌与振听** `[二手]` 凛上开花 wiki「形式聽牌…如果他人打出的牌也不能和则同样被视为振听」；`[一手]` 天凤 FAQ「無役の片聽待牌可使到自己同巡振聽而無法和牌」。

> **开关** `temporary_furiten_clear`：雀魂／天凤 `on_own_discard` ｜ WRC `on_own_draw_or_call`
> **开关** `furiten_on_no_yaku_wait`：雀魂 `true`（`[推定]`）｜ 天凤 `true`（`[一手]`）

### 6.4 形式听牌（形式聴牌 / 形式テンパイ）

**定义**：手牌**结构上已成听牌形**，但**无役**（不计悬赏役）——即使摸到/荣到和牌张也不能和牌。

| 项 | 规则 |
|---|---|
| **流局时是否算听牌** | **算**（可收不听罚符，庄家可据此连庄）`[二手]` 萌娘百科雀魂条目「有形式聽牌，不承認虛聽」 |
| **「不承認虛聽」** | 不存在「结构上不听牌却按听牌处理」的情形 |
| **听第 5 张牌** | **允许**：`手牌 = 纯手牌 + 副露手牌`，只要**纯手牌未用尽该牌种的 4 张** `[一手]` 天凤 |
| **空听 / 纯空听** | 所听牌已全部打出或用尽，**仍算听牌**（但 `[二手]` 中文维基同文件内自相矛盾 → 附录 C-3） |

> **开关** `formal_tenpai_counts`：雀魂 `true` ｜ 天凤 `true`（`[一手]`「形式聴牌あり。5枚目を待つ聴牌あり」）

### 6.5 多家和牌（双响 / 三家和）

**雀魂：无头跳，多家和牌全部结算** `[二手]` 萌娘百科雀魂条目「無頭跳搶和，有多家和牌，所有榮和均按逆時針進行結算」「沒有三家和了流局，所有和牌均進行結算」

| 规则集 | 双响 | 三家和 |
|---|---|---|
| **雀魂** | **两家都和** | **三家全和**（无三家和流局） |
| 天凤 | **两家都和** | **三家和 = 途中流局**（连庄） |
| JPML A | **头跳**（上家优先） | **三家和 = 流局** |
| WRC | **头跳** | **头跳**（无途中流局） |

```

  for each winner in counterclockwiseOrder(from discarder's next player):
      settle(winner)                    // 放铳者向每一位和牌者各付一份全额
  场供与立直棒 → 归「头跳家」            // = 逆时针方向第一个和牌者
  if (庄家 ∈ winners) → 连庄 ; else → 轮庄
```

**「头跳家」精确定义**：从放铳者的下家起逆时针数，**第一个和牌者**。

> **开关** `multi_ron`：雀魂 `all` ｜ 天凤 `double_only` ｜ 竞技 `atamahane`
> **开关** `triple_ron_abortive`：雀魂 `false` ｜ 天凤 `true` ｜ JPML `true` ｜ WRC `n/a`

### 6.6 抢杠（槍槓 / チャンカン）

**成立条件**：他家**加杠**所加的那张牌正好是自己和牌张。**后果**：**加杠不成立** → **不产生杠宝牌**；按**荣和**清算（放铳者 = 加杠者）。**抢大明杠不能**。**抢暗杠正常不能**，但**雀魂：国士无双可以**（`[二手]` 萌娘百科雀魂条目「國士無雙可以搶暗槓和牌」），**天凤：不可以**（`[一手]`「他家が暗槓した牌では国士無双はあがれない」）。**与一发可复合**（仅连续杠第 1 次）。**见逃抢杠**进入**同巡振听**，直到自己下一次摸牌 `[一手]`。番数 1 番（无限制）。

> **开关** `kokushi_robs_ankan`：雀魂 `true` ｜ 天凤 `false` ｜ JPML **官网自相矛盾** `[待核实]`（附录 C-14）｜ WRC `true`

### 6.7 岭上开花（嶺上開花）

开杠后摸岭上牌时**自摸和牌**（三麻含拔北后摸岭上牌）→ 1 番（无限制）。**符数正常计算自摸 2 符**（§8.5）。**与一发不复合**、**与海底不复合**。

### 6.8 和的时点与「同巡选择」

`[一手]` 天凤「同一巡内の選択ロン和了なし(加槓牌を含む)」——**不可等到看见别人是否和牌之后再决定自己是否和牌**；所有玩家必须在不知道他人选择的情况下独立决定。JPML 同（「同巡内のアガリ選択はできない」）。`[待核实]`：雀魂是否实装 → 附录 C-9。

### 6.9 和的判定流程（完整伪码）

```js
function resolveWin(player, tile, winType) {
  if (player.furiten && winType === 'ron') return REJECT;         // §6.3
  const decomps = enumerateDecompositions([...player.hand, tile], player.melds);
  if (decomps.length === 0) return REJECT;                        // 结构上不能和
  const candidates = [];
  for (const d of decomps) {
    const yaku = evaluateYaku(d, player, tile, winType);          // §7 / yaku.md
    if (sumHan(yaku.filter(y => !y.isDora)) < rules.minimum_han) continue;   // §6.2 起和
    const yakuman = yaku.filter(y => y.isYakuman);
    if (yakuman.length > 0) candidates.push(scoreYakuman(yakuman));          // §7.7 跳过符与宝牌
    else candidates.push(score(computeFu(d, yaku, winType, player),          // §8
                               sumHan(yaku), player.isDealer));              // §9（含悬赏役）
  }
  if (candidates.length === 0) return REJECT;                     // 无役
  return argmax(candidates, c => c.points);                       // 高点法
}
```

## 7. 役种

**役种全表见 [`yaku.md`](yaku.md)。** 本节只写**判定总则**——即「怎么把役种表接进引擎」。

### 7.1 复合与互斥

**复合（默认可叠加）**：不同役成立几个算几个，番数相加。**役牌可自叠加**（三元牌 3 种各 1 番；**连风牌刻子 = 场风 1 番 + 自风 1 番 = 2 番**，§7.7）；**小三元自动叠加役牌**（小三元 2 番 + 其中 2 组三元牌 2 番 = **最少 4 番**）；**食下役**副露后降番但仍与其他役复合；**役满之间可复合**（§7.6）。`[二手]` 凛上开花 wiki「役牌都是可疊加的」「小三元成立时，另计两组役牌」

**互斥分三类**，实现时必须分开处理：

| 类型 | 例子 | 处理方式 |
|---|---|---|
| **A. 取值互斥**（同一维度的不同档） | 立直 vs 两立直；一杯口 vs 二杯口 | 取高档，低档归 0 |
| **B. 拆解互斥**（牌型拆法不同） | 七对子 vs 二杯口/一杯口/对对和 | **分别按两种拆解各算一遍，高点法取胜者** |
| **C. 牌型互斥**（不可能共存） | 断幺九 vs 混全带；混一色 vs 清一色；混全带 vs 混老头；清老头 vs 七对子 | 直接判定，无需比较 |

```js
// A 类示例
riichiHan     = isDoubleRiichi ? 2 : (isRiichi ? 1 : 0);
iipeikouHan   = (dupPairs >= 2) ? 0 : (dupPairs === 1 ? 1 : 0);
ryanpeikouHan = (dupPairs >= 2 && menzen) ? 3 : 0;
```

### 7.3 宝牌不计入起和番（**最关键的一条**）

```
起和判定:  Σ(非悬赏役番数) >= minimum_han      // §6.2
最终番数:  Σ(非悬赏役番数) + Σ(悬赏役番数)
```

| 悬赏役 | 计入总番数 | 计入起和番 |
|---|---|---|
| 表宝牌 / 杠宝牌 / 里宝牌 / 杠里宝牌 / 赤宝牌 | ✅ | ❌ |
| **一发** | ✅ | ❌ |
| 拔北宝牌（三麻） | ✅ | ❌ |

**计入**：满贯/跳满/倍满/三倍满的界限判定；累计役满的 13 番门槛（上限判定）。
**不计入**：起和番数（`minimum_han`）；役满的倍数（役满时宝牌完全不加算）。

```js
const yakuHan = yaku.filter(y => !y.isDora).reduce((s, y) => s + hanOf(y), 0);
const doraHan = yaku.filter(y =>  y.isDora).reduce((s, y) => s + hanOf(y), 0);

```

`[一手]` 天凤「※懸賞役は縛りの飜数には数えない」；`[二手]` 萌娘百科雀魂条目友人场「無論幾翻縛的起和都不計寶牌」；`[二手]` 凛上开花 wiki「悬赏牌…和一发不能作为起和飜数」
**★ 易错点**：**两立直不是悬赏役**（计入门槛），而**一发是悬赏役**（不计入）。这个区别在 2 番缚/4 番缚下直接改变能否和牌。

### 7.5 暗刻的定义（三色同刻 / 三暗刻 / 四暗刻 / 符数共用）

**必须实现为一次判定、多处消费**，否则会出现符数与役种不一致：


| 情形 | 结果 |
|---|---|
| 双碰听**荣和** | 和牌张补成的刻子是明刻 → 只剩 3 暗刻 → **四暗刻不成立**（应判「三暗刻 + 对对和」） |
| 双碰听**自摸** | 和牌张补成的刻子是暗刻 → 4 暗刻 → **四暗刻成立** |
| **单骑**听（四暗刻单骑） | 4 组暗刻在听牌时已完成 → **荣和或自摸均成立** |
| **暗杠** | **算暗刻**（符数按杠计，与暗刻计数不冲突） |
| 碰出的刻子 | 不算暗刻 |

`[一手]` 天凤「※ロン和了で完成した刻子は明刻子とし順子は暗順子とする」；`[二手]` 中文维基三暗刻「自己一对X，然后荣和X，此时的XXX属于明刻，不是暗刻」

### 7.6 役满与倍数

## 8. 符数计算

### 8.1 逐项加符表

| 项 | 符数 | 适用条件 |
|---|---|---|
| **副底（底符）** | **+20** | **无条件加**（所有一般形） |
| **门清荣和** | **+10** | 门清 && 荣和。副露荣和 **+0** |
| **自摸** | **+2** | 门清/副露**都加**；**岭上开花也加**（§8.5） |
| **听牌符：单骑 / 嵌张 / 边张** | **+2** 各 | 边张 = 和牌张补成 `123` 的 3 或 `789` 的 7 |
| **听牌符：两面 / 双碰** | **0** | 双碰荣和补成的刻子按**明刻**加面子符 |
| **雀头符：三元牌 / 场风牌 / 自风牌** | **+2** 各 | 三项独立相加 |
| **雀头符：连风牌** | **+4** | 场风 == 自风 == 雀头 → 上面两项**各加 2**（§8.3） |
| **雀头符：客风、数牌** | **0** | |
| **面子符：顺子** | **0** | 所有顺子 0 符 |
| **面子符：中张明刻（2–8）** | **+2** | 碰出的、以及**荣和补成的刻子** |
| **面子符：幺九明刻（1/9/字）** | **+4** | |
| **面子符：中张暗刻 / 幺九暗刻** | **+4 / +8** | |
| **面子符：中张明杠 / 幺九明杠** | **+8 / +16** | 大明杠 **+ 加杠**（加杠算明杠） |
| **面子符：中张暗杠 / 幺九暗杠** | **+16 / +32** | |

**规律**（可用于生成查表，也可用于自检实现）：从「中张明刻 2 符」起，**暗刻 = 明刻×2；明杠 = 暗刻×2；暗杠 = 明杠×2**；幺九牌（1/9 数牌 + 全部字牌）恒为同档中张的 2 倍。`[二手]` 三源一致：中文维基符计算、麻雀豆腐 `rule-score-fu`、RCR 2016 规则书 §4.1
**★ 最容易错的一条**：字牌算「幺九」→ `中`（`7z`）暗刻 = **8 符**（不是 4 符）；`发` 暗杠 = **32 符**。`[二手]` 凛上开花 wiki「幺九=19萬19索19筒東南西北白發中」

### 8.2 符数切上（切り上げ）与适用范围

```
符数切上: 所有加符项累加完毕后，若个位不是 0，则【向上】取整到下一个 10
  // 32 → 40；38 → 40；102 → 110   （不是四舍五入）
```

**只对一般形有效**。三种情形**直接取固定值、不切上**：平和自摸（**20**）、七对子（**25**）、役满（**不计符**）。

**「一律进位」还是「只在自摸时进位」**：**一律进位**（荣和、自摸同样进位）。「自摸才进位」的说法**未在任何主流规则/平台中出现**，判定为误传。
**反证**（可用于验证实现）：一般形「底符 20 + 自摸 2 = 22 符」在实机上总是以 **30 符**出现（如副露平和形自摸 30 符），说明切上确实作用于自摸路径；而平和自摸走的是「直接把总符定为 20」这条路，与切上不冲突。`[二手]` 中文维基符计算「符合计后，符个位不是0时：个位变0 十位+1」；麻雀豆腐「符は下一桁を切り上げ！」

### 8.3 雀头符（连风牌的真实分歧）

```js
pairFu = (三元牌 ? 2 : 0) + (自风 ? 2 : 0) + (场风 ? 2 : 0);
// 连风牌 → 两项各加 2 = 4 符（雀魂/天凤/雀姬默认）；开关 renfon_pair_fu = 2 时只用一项
```

| 规则 / 平台 | 连风牌雀头符 | 可信度 |
|---|---|---|
| **雀魂** | **4 符** | 中——**两条独立二手来源一致**：中文维基符计算「（連風=W東，W南）天鳳&雀姬&雀魂=4符，有些规则2符」；萌娘百科雀魂条目「連風牌雀頭4符」 |
| **天凤 / 雀姬** | **4 符** | **高**（`[一手]` 天凤「連風牌は4符」） |
| 一般线下规则 / 多数雀庄 / 关东标准 | **2 符** | 高 `[二手]` 麻雀豆腐「雀頭が連風牌の時は2符で計算するのが一般的」 |
| JPML | **4 符** | 高 |
| 竞技（WRC 规则书） | **4 符**（符表 `Double wind 4`） | **但 JPML 官网的 WRC 摘要写 2 符** → 附录 C-15 |

> **开关** `renfon_pair_fu`：雀魂 `4` ｜ 备选 `2` ｜ 天凤 `4` ｜ 竞技 `4`（WRC 规则书）／`2`（JPML 摘要）

**逻辑自洽性**：连风雀头 = 同时是自风与场风 → 按「役牌雀头 +2」逐项相加即 4 符。**连风雀头不产生任何役**（雀头不成役），只影响符，且**破坏平和**。

### 8.4 特殊固定符

| 情形 | 符数 | 规则 |
|---|---|---|
| **平和 + 自摸**（ツモピン） | **固定 20** | 舍弃自摸的 2 符换取平和的 1 番；**不先加 2 再切上** |
| **平和 + 荣和** | **30** | 20（副底）+ 10（门清荣和） |


## 9. 点数计算

### 9.1 基本点公式与支付方式

```
基本点 = 符 × 2^(番 + 2)          封顶: 基本点 > 2000 → 取 2000（满贯）
```

> 指数里的 `2` 是「场ゾロ」（场棒，无条件附加的 2 番）。教学材料常省略它，写「符 × 4 × 2^番」（子）或「符 × 6 × 2^番」（亲），两者等价：子得点 = 基本点 × 4 = 符 × 4 × 2^(番+2)；亲得点 = 基本点 × 6。

| 情形 | 支付方式 |
|---|---|
| **子家荣和** | 放铳者付 **基本点 × 4** |
| **子家自摸** | 亲家付 **基本点 × 2**；另两个子家各付 **基本点 × 1** |
| **亲家荣和** | 放铳者付 **基本点 × 6** |
| **亲家自摸** | 三个子家**各付 基本点 × 2**（合计 基本点 × 6，故**亲自摸总收 == 亲荣和**） |

`[二手]` 麻雀豆腐「点数計算 計算式と早見表」；RCR 规则书 §4.3.1「基本点 = 符 × 2^(翻+2)」

### 9.2 满贯等级界限

| 名称 | 番数界限 | 基本点 | 子家荣和 | 子家自摸（子/亲） | 亲家荣和 | 亲家自摸（all） |
|---|---|---|---|---|---|---|
| （通常） | 1–4 番 | 符×2^(番+2)，封顶 2000 | 按表 | 按表 | 按表 | 按表 |
| **满贯** | **5 番**；或 1–4 番但**基本点 > 2000** | 2000 | 8000 | 2000 / 4000 | 12000 | 4000 |
| **跳满** | **6–7 番** | 3000 | 12000 | 3000 / 6000 | 18000 | 6000 |
| **倍满** | **8–10 番** | 4000 | 16000 | 4000 / 8000 | 24000 | 8000 |
| **三倍满** | **11–12 番** | 6000 | 24000 | 6000 / 12000 | 36000 | 12000 |
| **累计役满 / 役满** | **≥ 13 番** ／ 役满役 | 8000 | 32000 | 8000 / 16000 | 48000 | 16000 |
| **N 倍役满** | — | 8000 × N | 32000 N | 8000 N / 16000 N | 48000 N | 16000 N |

**★ 「满贯界限」有两条独立路径，不要混为一谈**：

```
路径 A（公式溢出，与开关无关）: 4 番 40 符 → 40×2^6 = 2560 > 2000 → 满贯
                              3 番 70 符 → 70×2^5 = 2240 > 2000 → 满贯
路径 B（切上满贯，开关控制）  : 4 番 30 符 → 30×2^6 = 1920 ≤ 2000
                              3 番 60 符 → 60×2^5 = 1920 ≤ 2000
```

### 9.3 切上满贯（切り上げ満貫）

**定义**：把基本点恰好 = **1920** 的两个组合——**（30 符, 4 番）** 与 **（60 符, 3 番）**——切上到 2000，直接按满贯结算。`if (kiriage_mangan && ((fu===30&&han===4)||(fu===60&&han===3))) basePoints = 2000;`

| 规则 / 平台 | 是否采用 | 出处 |
|---|---|---|
| **雀魂段位场** | **不采用** → 4 番 30 符 = **7700 / 11600** | `[二手]` 萌娘百科雀魂条目三麻打点表把 30 符 4 番单列为 7700/11600；另有 Yahoo!知恵袋高赞回答「雀魂は切り上げ不採用なので40符以上」 |
| 天凤**段位战** | **不采用** | **高** `[一手]`：官方手册把「切り上げ満貫」只列在**雀荘戦**差异项里，段位战章无此项 |
| 天凤**雀荘战** | **采用** | `[一手]`「■ ルール / 雀荘戦 … - 切り上げ満貫」 |
| JPML **A / B 规则** | **不采用 / 采用** | `[一手]`「30 符 4 翻は満貫に切り上げず、子 7,700 点、親 11,600 点とする」／「30 符四ハンは切り上げ満貫となり 8,000、12,000」 |
| **WRC** | **采用** | `[一手]`「A base value of 1920 points…is rounded up to 2,000 points」 |
| M 联赛 | 采用 | `[二手]` |

> **开关** `kiriage_mangan`：雀魂 `false` ｜ 备选 `true` ｜ 天凤段位战 `false` ｜ 竞技 `false`（JPML A）／`true`（WRC、JPML B）

**注意**：**「符数切上」（§8.2）、「点数切上」（§9.4）、「切上满贯」（本节）是三件不同的事**，许多人把「切上满贯」误记成「切上符」。

### 9.4 支付零头进位（必须精确实现）

```
每一笔【实际支付额】都【向上进位到 100 点】（不是四舍五入）
谁承担零头：支付方各自承担 —— 即分别进位，不是先加总再进位
```

```js
const ceil100 = (x) => Math.ceil(x / 100) * 100;
childPays    = ceil100(basePoints * 1);   // 子家自摸：两个子家各付
dealerPays   = ceil100(basePoints * 2);   // 子家自摸：亲家付 ／ 亲家自摸：每子付
ronPay       = ceil100(basePoints * 4);   // 子家荣和
ronPayDealer = ceil100(basePoints * 6);   // 亲家荣和
```

**由此产生的正确「异常」**（不是 bug）：

| 现象 | 例 |
|---|---|
| **自摸总收 > 荣和收入** | 亲家 30 符 3 番：荣和 5800 → 自摸每子付 `ceil100(960×2)` = 2000 → 共收 **6000**（多 200） |
| **自摸总收 == 荣和收入** | 子家 25 符 3 番：基本点 800 → 子付 800、亲付 1600 → 荣和 3200，自摸 800+800+1600 = 3200 |
| 三麻自摸损下亲/子自摸总收相等 | §13.4 |

**错误做法**：先算「子家自摸总额」再除以 3 分摊；或对总额进位后再分摊。
`[二手]` 麻雀豆腐「点数の下二けたが端数となった場合は切り上げとなります」「ロンよりツモアガりの方が点数が多くもらえるケースがあります」；RCR 规则书 §4.3.1「取顶到百」

### 10.4 流局满贯（流局満貫 / 流し満貫）

**成立条件**：荒牌流局时，① 自己打出的牌**全部为幺九牌**；② 这些牌**全部未被他人吃/碰/杠**。**自己不需要听牌**；**自己鸣牌不影响成立**；**关键约束**是「**自己的牌河没有被鸣牌**」，**不是**「自己没有鸣牌」。**不进行听牌清算**，按**流满清算**（满贯点数）；**若庄家听牌则连庄**（与普通荒牌流局同条件）。`[待核实]`：两家以上同时成立时如何结算 → 附录 C-11。

`[二手]` 萌娘百科雀魂条目「有流局滿貫。當發生流滿時不進行聽牌清算而是流滿清算，若莊家聽牌則連莊」「流局滿貫需要在自己的牌河沒有被鳴牌的情況下才成立。自己可以鳴牌。」
`[一手]` 天凤「流し満貫あり。聴牌清算を満貫清算に代替。親の聴牌で連荘。」「流し満貫は、自分の河が鳴かれていない場合に成立。自分が鳴いた場合でも成立。」
**常见误解纠正** `[二手]`：「流局满贯必须门清、自己不能鸣牌」是**错的**。

```js
function isNagashiMangan(player) {
  return player.discards.length > 0                     // 至少要打出过牌
      && player.discards.every(t => isYaochu(t))         // 全部幺九牌
      && player.discards.every(t => !t.wasCalled);       // 全部未被鸣（被鸣走的牌仍在牌河，标记 wasCalled）
  // 鸣牌后打出的牌也计入牌河，同样必须全是幺九牌
}
```

**★ 雀魂与天凤在「复合役满」上的关键差别**（**包牌上最容易踩坑之处**）：**雀魂** = **包牌支付规则只适用于「包牌役满」那一部分**，其余役满**正常计算**；**天凤** = **把复合役满整体按包牌分摊**（例：大四喜 + 字一色，字一色部分也一起包）。
`[二手]` 萌娘百科雀魂条目「當涉及多役滿複合的情況時，點數支付規則僅適用於包牌役滿的部分，其餘正常計算。」；实例「大四喜＋字一色，包牌者付大四喜一半＋积棒，放铳者付大四喜一半＋字一色全部」

```js
function settlePao(winner, paoPlayer, discarder, yakumanList, winType) {
  const paoPart   = yakumanList.filter(y =>  rules.pao_yaku.includes(y));
  const otherPart = yakumanList.filter(y => !rules.pao_yaku.includes(y));
  if (rules.pao_scope === 'pao_part_only') {          // 雀魂
    const p = scoreYakuman(paoPart), o = scoreYakuman(otherPart);
    if (winType === 'tsumo') {
      transfer(paoPlayer, winner, p);                  // 包牌部分：包牌者全额
      transferAll(others, winner, o);                  // 其余部分：正常三家分摊
    } else {
      transfer(paoPlayer, winner, p / 2);
      transfer(discarder, winner, p / 2);              // 包牌部分折半
      transfer(discarder, winner, o);                  // 其余部分：放铳者全额
    }
  } else {                                            // 天凤：整体包
    const total = scoreYakuman(yakumanList);
    if (winType === 'tsumo') transfer(paoPlayer, winner, total);
    else { transfer(paoPlayer, winner, total/2); transfer(discarder, winner, total/2); }
  }
}
```

**积棒（本场棒 + 立直棒）归属**：雀魂 = 包牌者付「包牌役满一半 + 积棒」`[二手]`；天凤 = **本场棒也需包**`[一手]`「積み棒は包。」；JPML/WRC = **积棒由放铳者负担**。

## 12. 终局与结算

### 12.1 局数与终局判定

```
东风战: 最大局数 = 南 4 局（东 1-4 → 南入 → 南 1-4）
东南战: 最大局数 = 西 4 局（东 1-4 → 南 1-4 → 西入 → 西 1-4）
```

```js
function shouldEndGame(state) {
  if (state.players.some(p => p.score < 0)) return {end:true, reason:'hakofuri'};   // ① 击飞优先
  if (!state.isAllLastOrLater) return {end:false};
  if (state.roundIndex > state.maxRoundIndex) return {end:true, reason:'max_round'};// ② 到达最大局数
  const anyoneOver = state.players.some(p => p.score >= state.requiredPoints);
  if (state.dealerRenchan && state.dealer !== state.rank1Player)
    return {end:false, reason:'renchan_priority'};       // ③ 庄家连庄且非一位 → 连庄优先
  if (state.dealerRenchan && state.dealer === state.rank1Player)
    return {end:true,  reason:'dealer_top_renchan'};     // ④ 庄家连庄且为一位 → 结束
  if (!anyoneOver) return {end:false, reason:'enter_extra_round'};  // ⑤ 无人超 30000 → 加时
  return {end:true, reason:'someone_over'};              // ⑥ 有人超 30000 且庄家未连庄 → 结束
}
```

`[二手]` 萌娘百科雀魂条目：「有東風戰南入、東南戰西入，當沒有玩家超過30000點時將進行加時賽。」「加時賽最長加時到南風局結束或西風局結束，強制進行結算。」「加時賽中一旦有玩家超過30000點即立刻結束遊戲，但若存在莊家連莊且當前莊家不是一位的情況時，連莊優先。」「東四局/南四局結束時，莊家為一位，超過30000點且滿足要求可以連莊時，不再連莊，結束遊戲。」

### 12.3 顺位与马点

```
最终得分 = (终局点数 − 起始点数) / 1000 + 马点 + オカ（返点差）
```

| 规则集 | 起始点 | 一位必要点数 | 马点 |
|---|---|---|---|
| **雀魂四人段位场** | **25000** | **30000** | **+15 / +5 / −5 / −15** |
| **雀魂三人段位场** | **35000** | **40000** | **+15 / 0 / −15** |
| 天凤四人 / 天凤三人 | 25000 / 35000 | 30000 / 40000 | **+10 / −10** ／ **+20 / 0 / −20** |
| JPML A | 30000（**无オカ**） | 30000 | **按浮き人数变动**（2 人浮き +8/+4/−4/−8；1 人浮き +12/−1/−3/−8；3 人浮き +8/+3/+1/−12），同点者均分 |

### 12.4 场供归属与同点顺位

**场供归属**：和牌时 → 和牌者取得全部供托 ＋ 本场（`300 × n`）；**多家和牌 → 头跳家**（§6.5）；流局 → **留场**累积；终局 → **由一位获得全部场供** `[二手]` 萌娘百科雀魂条目（JPML/WRC **无人取得**）。
**区分两个概念**：**供托（立直棒）** = 立直者支付的 1000 点/根，桌上累积；**本场（積み棒）** = 连庄计数，和牌时按 `300 × n` 支付，**不是桌上累积的点棒**。雀魂条目说的「一位获得全部**场供**」指的是**供托（立直棒）**（`[推定]`：与天凤「終了時の供託はトップ取り」对应）。

**同点顺位**：终局同点时按**东一局的座次顺序**决定顺位：`东一局东家（起家） > 南家 > 西家 > 北家`。`[二手]` 萌娘百科雀魂条目「遊戲結束時，存在玩家相同點數的情況下，由東一局的座位順序決定順位」；`[一手]` 天凤「終了時に同点の場合は東1局の風順で順位を決定」。**注意**：这**不是**「同点者均分顺位点」（那是 WRC 的做法）。

### 12.5 终局点数清算

**雀魂** `[待核实]`：未见明文，推定**不四舍五入** → 附录 C-12。**天凤**：2009-08-01 前四舍五入至 1000 点，`[一手]` **2022-01-21 已废止**（「終了時の得点の1000点未満の四捨五入を廃止」）。**WRC**：`(points − 30000)/1000 + uma`，**不舍入**。

### 13.3 自摸损（ツモ損）

**雀魂三人段位场固定采用「有自摸损」** `[二手]` 萌娘百科雀魂条目三麻「段位場固定採用有自摸損方式」；友人场可改为「无自摸损（丸取）」。

```
子家自摸（有自摸损）: 亲家付 基本点 × 2；另一个子家付 基本点 × 1
                      合计 = 3 × 基本点 = 荣和(4 × 基本点) 的 3/4
亲家自摸（有自摸损）: 两个子家各付 基本点 × 2
                      合计 = 4 × 基本点 = 荣和(6 × 基本点) 的 2/3
```

**★ 结构性质（可用于自检实现）**：**有自摸损时，亲家自摸与子家自摸的总收完全相等**（都 = 4 × 基本点），即「**亲/子自摸比 = 1.0**」，而四麻是 1.5。

`[二手]` 萌娘百科雀魂条目三麻「自摸損指的是在玩家自摸時，在正常得點中扣除北家的支出，導致親家自摸的點數比榮和低1/3，而子家則低1/4」；`[一手]` 天凤官方博客「子満貫ロン ⇒ 8000点；子満貫ツモ ⇒ 子2000点＋親4000点＝6000点」

| 满贯等级 | 子家荣和 | 子家自摸（合计） | 亲家荣和 | 亲家自摸（合计） |
|---|---|---|---|---|
| 满贯 5 番 | 8000 | 2000/4000 [6000] | 12000 | 4000 all [8000] |
| 跳满 6–7 番 | 12000 | 3000/6000 [9000] | 18000 | 6000 all [12000] |
| 倍满 8–10 番 | 16000 | 4000/8000 [12000] | 24000 | 8000 all [16000] |
| 三倍满 11–12 番 | 24000 | 6000/12000 [18000] | 36000 | 12000 all [24000] |
| 役满 / 累计役满 ≥13 番 | 32000 | 8000/16000 [24000] | 48000 | 16000 all [32000] |

**本表已用脚本按公式复算，逐格一致**（`mahjong/tools/gen_score_table.py` 的「比对3/比对4」输出，见附录 B.2）。
**无自摸损（丸取）**：把北家的支出平分成两份由另两家承担；子家自摸为 3/8、5/8 分割，亲家自摸为平分。

### 13.4 拔北（抜き北 / 北抜き）

**北（`4z`）在三麻中可作为「拔北宝牌」拔出**，代替其作为普通手牌。

| 项 | 规则 |
|---|---|
| **操作** | 手牌中有北时**可以拔出**，之后**摸一张岭上牌**（**但不翻杠宝牌指示牌**） |
| **每张拔出北** | **最终番数 +1** |
| **宝牌指示牌为北（`4z`）时** | 拔出的每张北**额外计宝牌 1 番**，即**每张 2 番**（未拔出的北只算普通宝牌 1 番） |
| **岭上牌** | 三麻 **8 张**，故拔北 + 开杠总共最多 8 次岭上摸牌 |
| **拔北后摸岭上牌自摸** | 计**岭上开花** |
| **他家可以「抢北和」** | 但**不计抢杠**，因此和北的一家**必须有其它役** |
| **拔出的北视为手牌而非舍张** | 故拔北后仍允许荣和别家的拔北，**不算振听** |

`[二手]` 萌娘百科雀魂条目三麻全部条目；`[一手]` 天凤三麻章「北は抜きドラ」「抜いた北は役満以外でも和了可能」

**★ 拔北视为「近似鸣牌」——三麻最重要的一条**：在**某些判定**上等同鸣牌，在**另一些判定**上不等同。

| 判定 | 是否等同鸣牌 | 说明 |
|---|---|---|
| **碰后不可直接拔北** | **是** | 「拔北是近似於鳴牌的行為，因此碰後不可以直接拔北」 |
| **破除一发 / 地和 / 九种九牌 / 两立直** | **是** | 四项全破 |
| **是否算副露（破坏门清）** | **`[待核实]`**（推定 `false`） | 雀魂/天凤条目**均未明说**。推定不破坏门清（否则三麻几乎无法立直）→ 附录 C-5 |
| **拔出的北是否计入断幺九** | **不计入**（视同不存在） | `[二手]` 凛上开花 wiki 断幺九条目 |
| **拔出后是否构成舍牌振听** | **否** | 「拔出的北寶牌視為手牌而非舍張…不算振聽」 |
| **北作面子时 / 作雀头时** | 计为**客风** ／ **不计任何符**（客风雀头 0 符） | `[一手]` 天凤「北を面子で使用した場合はオタ風」；`[二手]` 萌娘百科雀魂条目 |

**一发消除时机** `[一手]`：「純正巡消しは発声＆和了打診後（加槓/抜き)、嶺上ツモの前とする」。

```js
function nukiKita(player) {
  if (!rules.sanma || player.hand.count('4z') === 0) return REJECT;
  if (player.justPonned) return REJECT;              // 碰后不可直接拔北
  player.hand.removeOne('4z');
  player.nukiKita.push('4z');                        // 单独记录，不算舍张
  breakIppatsu(); breakChiho(); breakDoubleRiichi(); invalidateKyuushuKyuuhai();
  player.drawRinshan();                              // 摸岭上牌（不翻杠宝牌）
  // 结算时：han += nukiKita.length;
  //         if (doraIndicator === '4z') han += nukiKita.length;   // 每张共 2 番
}
```

> **开关** `nuki_kita`：雀魂三麻／天凤三麻 `true` ｜ 四麻 `false`
