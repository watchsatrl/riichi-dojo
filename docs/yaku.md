## 1. 记号与判定总则

### 1.1 记号

| 记号 | 含义 |
|---|---|
| **门清限定** | 副露后该役**不成立**（番数归 0） |
| **食下 N** | 副露后降为 N 番（`N = 0` 即等同门清限定） |
| **无限制** | 副露不影响 |
| **悬赏役** | 计番但**不计入起和番**（见 §5.1） |

**「副露」的定义**（影响上表全部判定）：吃、碰、**大明杠**、**加杠**。
**暗杠不算副露**（仍视为门清）。`[一手]` 天凤手册、`[二手]` 通用规则

**「门清（门前清）」的定义**：本局中没有吃过、碰过、大明杠过、加杠过。只开过暗杠仍是门清。

### 1.2 判定总则（实现顺序）

```
判定和牌役时按以下顺序，任一步失败即该役不成立：

1. 拆解和牌形（标准形 4面子+1雀头 / 七对子形 / 国士形）
   - 若存在多种拆解，全部枚举，最后按「高点法」取总点数最高者（§5.5）
2. 对每一种拆解，逐条检查每个役的成立条件
3. 剔除互斥役（§5.2 / §5.3）
4. 番数 = Σ(成立役的番数，按门清/副露取对应值) + Σ(悬赏役番数)
5. 起和判定：若 Σ(非悬赏役番数) < 起和番数 → 不能和牌（雀魂段位场起和番数 = 1）
   —— 注意「宝牌不计入起和番」，见 §5.1
6. 若含役满役 → 走役满分支（§4.4 / §4.5），跳过符数计算，不与非役满役复合，宝牌不加算
7. 否则计算符数（[rules.md](rules.md) §8）→ 查点数表（[rules.md](rules.md) §9）
```

## 5. 必须写清的特殊情形

### 5.1 宝牌（悬赏牌）不计入起和番

**结论**：悬赏役**计番**（计入总番数、参与满贯/跳满等界限判定，也计入累计役满的 13 番），但**不能作为起和所需的番数**。

| 悬赏役 | 是否计入总番数 | 能否充当起和番 |
|---|---|---|
| 表宝牌 / 杠宝牌 / 里宝牌 / 赤宝牌 | 是 | **否** |
| 一发 | 是 | **否** |
| 拔北宝牌（三麻） | 是 | **否** |

**判定式**：
```
canWin = (Σ 非悬赏役番数) >= 起和番数        // 雀魂段位场起和番数 = 1
totalHan = Σ 全部役番数（含悬赏役）
```

`[一手]` 天凤手册「※懸賞役は縛りの飜数には数えない」
`[二手]` 萌娘百科雀魂条目友人场「一翻縛、二翻縛和四翻縛（**無論幾翻縛的起和都不計寶牌**）」；凛上开花 wiki「并不是所有算飜的都有役，例如悬赏牌（包括赤宝、北宝牌等）和一发不能作为起和飜数」

### 5.2 一杯口 与 二杯口 同时成立

**结论**：**不复合**。两者是同一维度的互斥取值。

```
相同顺子组数 = 1  →  一杯口 1 番
相同顺子组数 = 2  →  二杯口 3 番（不再加一杯口）
```

`[二手]` 中文维基二盃口「不和一杯口複合」

**实现**：`iipeikouHan = (dupPairs >= 2) ? 0 : (dupPairs === 1 ? 1 : 0)`，`ryanpeikouHan = (dupPairs >= 2 && menzen) ? 3 : 0`。
注意 `dupPairs` 必须按**同一数字的顺子对数**统计：`1112345678999` 这类形可能同时有多组，需枚举拆解。

### 5.3 二杯口 与 七对子

**结论**：**不复合，二选一**，按**高点法**取实际点数高者（不是简单取番数高者）。

- 同一副牌既满足二杯口（3 番）又满足七对子（2 番）时，**通常取二杯口**。
- `[二手]` 中文维基二盃口「不和七对子複合（七對和二盃，二選一）」；七對子「不與二盃口複合，要麼七對，要麼二盃（通常是肯定只算二盃）」
- **必须真的算点数再比**，不能只比番数：二杯口 3 番 40 符荣和 5200 vs 七对子 2 番 25 符荣和 1600；但七对子可带立直/自摸/宝牌等叠加，理论上存在七对子胜的构型。
- **七对子与一杯口**：主流（雀魂/天凤/RCR）**不复合**。理由是拆解互斥——一副牌不可能同时拆成 7 组对子又含顺子。`[待核实]` 少数线下规则允许「4 张同牌当 2 对」从而七对+一杯并存，但**未找到任何主流规则出处**，**不推荐实现**。

**实现要点**：七对子判定成功后，不再做顺子役判定；反之按顺子拆解若能得更高点数，取顺子拆解。

### 5.4 平和（Pinfu）的定义

**四个条件，缺一不可**：

| # | 条件 | 判定式 |
|---|---|---|
| 1 | **门清** | `!isOpen`（暗杠不算副露，故暗杠不破坏平和） |
| 2 | **4 组面子全为顺子** | `melds.every(m => m.type === 'shuntsu')` |
| 3 | **雀头不是役牌** | `!isYakuhaiPair(pair)`，即雀头 ∉ {三元牌} ∪ {场风} ∪ {自风}。**连风牌雀头也不行**（连风 = 场风 ∩ 自风，仍是役牌） |
| 4 | **听牌形必须是两面听** | 和牌张补成的搭子是 `ryanmen`。坎张/边张/单骑/双碰均不成立 |

`[二手]` 中文维基平和（明确「門前清 / 雀頭不能是役牌 / 3 顺子 + 1 雀头 + 1 两面搭子」）；`[二手]` 凛上开花 wiki 役种表「只有顺子、雀头不能是自风或场风或三元牌，且两面听牌」

**易错点（`11223344` 型 / `33456` 型）**：和牌形存在多种拆解时，听牌形由**最终选定的那个拆解**决定。举例：
- `334567m + …荣和 7m`：若拆成 `33m + 456m + 7m7m…`（单骑）则无平和；若拆成 `345m + 67m` 听 5/8 的**两面**形则可保留平和。
- `334567m + …荣和 8m`：可拆成 `33m（雀头）+ 345m + 678m`，两面听，**成立平和**。`[二手]` 中文维基平和例 3 / 例 4

**实现**：不要先判「是否平和」再算符；正确做法是**枚举全部合法拆解 → 各自算总分 → 取最高**，其中「平和」作为一个可选的役出现在某些拆解里。

### 5.5 高点法（多解取最高）

**结论**：和牌形存在多种拆解、或存在多种役的组合方式时，取**实际支付点数最高**的一种。

```
candidates = enumerateAllDecompositions(hand)
best = argmax over candidates of (totalPoints(candidate))
// 注意：比较的是「点数」而非「番数」
// 番数相同时再比符数；两者都相同时结果一致，任一即可
```

`[二手]` 凛上开花 wiki「高点法」条目；中文维基点数计算「役和符，有多种可能性的时候，需要按较高的方式去计算」
**实现陷阱**：高点法必须在**符数计算之前**就确定拆解，因为符数与役种都依赖拆解。

### 5.8 二杯口的「4 张同牌」形态

| 役 | 4 张同牌能否用 |
|---|---|
| 二杯口 | **可以**。例：`1111m 2222m 3333m + 77m` 可拆为 `111m+111m / 222m+222m / 333m+333m` = 两组一杯口 ×2 = 二杯口 `[二手]` 中文维基二盃口「并不像七對子那樣，和牌不能用4張同樣牌」 |
| 七对子 | **不可以**。`4 张同牌不能当作 2 组对子` → 故「绿一色 + 七对子」「清老头 + 七对子」**不可能成立** `[二手]` 中文维基七對子 |

### 5.9 岭上开花计自摸 2 符

`[一手]` 天凤手册「嶺上ツモも2符加算」；`[二手]` 萌娘百科雀魂条目「嶺上開花情況下正常計算自摸2符」。四套规则（雀魂/天凤/JPML/WRC）**一致**。

### 5.10 平和自摸 20 符 / 七对子 25 符

| 情形 | 符数 | 规则 |
|---|---|---|
| 平和 + 自摸 | **固定 20 符** | 舍弃自摸的 2 符换取平和的 1 番；**不做切上** |
| 七对子（荣和/自摸同） | **固定 25 符** | 无视其他一切加符项（不加门清荣和、不加自摸符、不加单骑符），**也不做切上** |

`[二手]` 萌娘百科雀魂条目「平和自摸20符」「七對子無論銃和自摸均固定25符」；`[一手]` 天凤「ツモピン20符」「七対子は25符2飜、ツモ符なし」

### 5.12 暗刻的定义（三色同刻 / 三暗刻 / 四暗刻共用）

| 问题 | 结论 |
|---|---|
| 碰/明杠出的刻子算暗刻吗？ | **不算** |
| **暗杠**算暗刻吗？ | **算**（符数按杠计，但暗刻计数按刻计） |
| **自摸**补成的刻子算暗刻吗？ | **算暗刻** |
| **荣和**补成的刻子算暗刻吗？ | **不算，算明刻** `[一手]` 天凤「ロン和了で完成した刻子は明刻子とし順子は暗順子とする」 |
| **双碰听荣和**能否成立四暗刻？ | **不能**。和牌张补成的刻子是明刻 → 只剩 3 暗刻 → 「三暗刻 + 对对和」`[一手]` 天凤役种表「门清对对和，双碰听牌，**只能自摸**」 |

**实现**（关键，直接决定 3 个役的成立）：

```js
// 荣和时：把和牌张所在的那一组刻子标记为明刻
for (const meld of decomposition.melds) {
  if (meld.type === 'koutsu' && meld.containsWinTile && winType === 'ron') {
    meld.concealed = false;              // ← 荣和补成的刻子降级为明刻
  }
}
ankouCount = decomposition.melds.filter(m => m.type === 'koutsu' && m.concealed).length;
// 暗杠 = { type:'kantsu', concealed:true } 也计入 ankouCount
```

**同时影响符数**：该刻子按**明刻**计符（中张 2 / 幺九 4），而不是暗刻的 4/8。

### 5.13 役满的复合规则

| 情形 | 结论 |
|---|---|
| 役满役 **之间**能否复合 | **能**。例：大四喜 + 字一色 = 2 倍役满；天和 + 四暗刻单骑 = 3 倍（雀魂） |
| 役满役能否与**非役满役**复合 | **不能**。例：四暗刻不与对对和复合；九莲宝灯不与清一色复合 |
| 役满役能否与**宝牌/赤宝/里宝**复合 | **不能**（不加算） |
| 役满是否计符数 | **不计**。按固定点数结算（子 32000 / 亲 48000，双倍翻倍） |

`[一手]` 天凤「役満は複合あり」；`[二手]` 中文维基役滿「一般規則下役満役可以與役満役複合，但不能與懸賞牌以及役満役以外的役種複合」；`[二手]` 萌娘百科雀魂条目「役滿不計符數，不複合非役滿役。但多種役滿之間可以複合。」

**实现**：

```js
if (yakumanList.length > 0) {
  const mult = yakumanList.reduce((s, y) => s + YAKUMAN_MULTIPLIER[y], 0);
  return { points: 8000 * mult, fu: null, han: null, yaku: yakumanList };
  // 注意：完全跳过符数、跳过宝牌、跳过非役满役
}
```

**例外（青天井）**：不封顶、按 `符 × 2^(番+2)` 一路算下去的规则下需要计算役满的符。雀魂/天凤/雀姬**均不采用**青天井。

### 5.14 国士无双的符数

`[二手]` 中文维基國士無雙「國士無雙的符，并没有统一。但平常不需要计算國士無雙的符。」
